Currently a WIP: A note-taking app built for university students, but can be used by anyone. The features of the MVP include the ingestion of iCal URLs, and the ability to create notes and sub-tasks for each calendar event. Currently implementing standalone note-taking, and in the future, the ingestion of several iCal URL's simultaneously, a calendar view, and cloud data backup.
